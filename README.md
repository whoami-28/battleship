# ⚓ Морской Бой (Тетрадь в клеточку) • Battleship Online

> **Классический «Морской Бой» в школьной тетрадке в клетку** с поддержкой сетевой игры для двух игроков в реальном времени, рисованными кораблями, физической анимацией полета снарядов и реалистичным звуком.

## 📖 О проекте

Проект воссоздаёт ту самую атмосферу игры на уроках и переменах:
- **Лист в клетку**: поле стилизовано под настоящий тетрадный лист с нежно-голубой сеткой 5×5 мм и красными полями.
- **Школьные чернила и карандаш**: рукописные шрифты (`Caveat`, `Neucha`), жирные красные крестики попаданий `✕`, синие чернильные кляксы промахов `•` и легкие карандашные точки ореола.
- **Интересные векторные корабли (SVG)**: вместо монотонных квадратов каждый корабль отрисован от руки — с орудийными башнями, рубками, клубами дыма и флагами.
- **Размеренный темп**: навесная параболическая траектория полёта артиллерийского снаряда со свистом Доплера и тенью на бумаге (~750 мс) создаёт настоящее напряжение перед раскрытием результата залпа.
- **Реалистичный звук**: физические звуковые эффекты (тяжёлый залп орудий с суб-басом, взрывы, гидроудар и всплеск воды) синтезированы через алгоритмы DSP в формате WAV (16-bit PCM, 44.1 кГц).

## 🎯 Основные возможности

### 🌐 Сетевой мультиплеер (2 игрока)
- Создание комнаты в 1 клик с генерацией короткого кода (например, `NAVY-481`) и прямой ссылки.
- Подключение по ссылке: второй игрок открывает ссылку (поддерживается URL-параметр `?room=КОД`) в соседней вкладке, окне инкогнито или на смартфоне/ноутбуке в локальной сети.
- **Секретность расстановки**: сервер никогда не передаёт клиенту координаты кораблей соперника до их повреждения или потопления (полная защита от подглядывания в DevTools).
- Синхронное начало боя при готовности обоих капитанов.
- Система реванша: перезапуск партии одной кнопкой без пересоздания комнаты.
- Быстрые эмодзи-записки на полях (🎯, 💥, 🌊, 🚢, 🫡, ✏️, 😎).

### 🤖 Одиночная игра против бота
- Интеллектуальный тактический бот без «читерства» — играет по-человечески:
  - Случайный поиск по секторам вместо роботизированной математической четности.
  - Естественные ошибки и промахи (35% шанс отвлечься или сделать холостой выстрел при добивании).
  - Пауза на «раздумья» (1.5–2.2 сек) с показом статуса прицеливания и анимацией залпа на поле игрока.

### 📐 Правила русского морского боя
- **Сетка 10×10**: буквы А–К (без буквы «Й») и цифры 1–10.
- **Состав флота из 10 кораблей** (20 палуб суммарно):
  - 1 × **Линкор** (4 клетки)
  - 2 × **Крейсера** (3 клетки)
  - 3 × **Эсминца** (2 клетки)
  - 4 × **Катера** (1 клетка)
- **Буферная зона**: корабли не могут касаться друг друга ни бортами, ни углами (дистанция не менее 1 клетки).
- **Очередность ходов**: при попадании или потоплении корабля стрелявший делает **ещё один выстрел**; при промахе ход переходит сопернику.
- **Автоматический ореол**: после уничтожения корабля клетки вокруг него автоматически обводятся точками промаха (с поочередной прорисовкой под звук поскрипывания ручки).

### 🖥️ Умное масштабирование под экран
- Интерфейс автоматически определяет высоту и ширину окна браузера (`updateAppScale`) и подгоняет лист, чтобы игра **на 100% помещалась на экране без вертикального скролла**.
- В верхней панели доступны кнопки ручного зума: `[-]`, `[Экран]` (авто-подгонка) и `[+]`.

| Класс корабля | Палуб | Описание живого корабля | Текстура после потопления |

| **Катер** | 1 | Патрульный катер с пулемётным щитом и морским флагом | Дымящиеся обломки и флаг над водой |

## 🚀 Быстрый старт

### Требования
- Установленный **Node.js** (версии 18 или новее).

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```
Сервер запустится по адресу: **`http://localhost:3000`**

### 3. Запуск тестов
```bash
# Модульные тесты игровой логики
npm test

# Сквозной тест сетевого мультиплеера
node test/multiplayer.test.js
```

## 🎮 Как играть с другом по сети

1. Откройте страницу **`http://localhost:3000`**.
2. Введите свой позывной и нажмите **«Создать комнату»**.
3. Нажмите кнопку **«🔗 Скопировать ссылку»** в верхней панели комнаты.
4. Отправьте ссылку второму игроку (он открывает её в любой вкладке или на другом устройстве).
5. Расставьте корабли:
   - Вручную: выберите корабль в доке, поверните клавишей **`R`** или кнопкой, кликните на поле.
   - Автоматически: нажмите кнопку **«🎲 Случайно»**.
6. Нажмите **«⚔️ В БОЙ! ГОТОВ»**.
7. После готовности обоих игроков игра начнётся автоматически!

## 🛠️ Стек технологий

- **Backend**: Node.js, Express, Socket.io (WebSocket).
- **Frontend**: Чистый нативный JavaScript (ES6+), HTML5, CSS3, SVG (векторная графика кораблей).
- **Шрифты**: Google Fonts (`Caveat`, `Neucha`).
- **Аудио**: Web Audio API + синтезированные файлы формата 16-bit PCM WAV (44.1 кГц).
